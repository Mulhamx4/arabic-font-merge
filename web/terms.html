شروط الاستخدام

ملاحظة: هذا النص صياغة عملية تلخّص الالتزامات الفعلية للأداة، وليس نصًا مراجَعًا قانونيًا. راجعه مع مختص قبل الإطلاق العام.

١ — حقك في تعديل الخط

أنت تقرّ بأنك تملك حق تعديل كل ملف ترفعه، بموجب الرخصة التي حصلت عليها معه. الأداة تقرأ ما وضعه المسبك داخل الملف وتتصرف بناءً عليه: إذا كان بت Restricted License Embedding مضبوطًا في OS/2.fsType تتوقف الرحلة، وإذا كانت الرخصة SIL Open Font License تُفرض إعادة التسمية. لكن هذه إشارات آلية لا تُغني عن مسؤوليتك: غياب الإشارة ليس إذنًا.

٢ — المعالجة المحلية

كل المعالجة تجري داخل متصفحك. الأداة لا تستقبل ملفاتك ولا تخزّنها ولا ترسلها إلى أي خادم، ولا يوجد خادم يستقبلها أصلًا. القيود التقنية التي تجعل ذلك ممكنًا موصوفة في كيف تعمل الأداة.

٣ — رسوم العملات

رسوم رمز الريال السعودي والدرهم الإماراتي والريال العماني مأخوذة من الجهات الرسمية المصدِرة (البنك المركزي السعودي، مصرف الإمارات المركزي، البنك المركزي العماني) وتُضاف كما هي دون إعادة رسم. استخدامك لها يخضع لما تحدده تلك الجهات، لا لهذه الأداة.

٤ — لا ضمان

الأداة تُقدَّم كما هي، بلا ضمان من أي نوع. الملف الناتج مسؤوليتك أنت: مسؤوليتك أن تختبره قبل الاعتماد عليه، وأن تتأكد من صلاحيته لأي استخدام تجاري تنويه. تقرير التحقق داخل الصفحة أداة مساعدة لا شهادة صلاحية.

٥ — الختم داخل الملف

يُضاف إلى سجل الإصدار داخل الملف (nameID 5) نص يفيد بأن الملف عُدِّل بهذه الأداة. الغرض شفافية لأي فاحص لاحق: من يفتح الملف يعرف أنه ليس كما شحنه المسبك.

٦ — لا تتبّع

لا تُجمع أي بيانات عن محتوى ملفاتك: لا أسماء خطوط، ولا أحجام، ولا أي شيء مقروء من الملف.

Terms of use

Note: this text is a working draft summarising the tool's actual obligations. It has not been through legal review — have it checked before a public launch.

1 — Your right to modify the font

You confirm that you hold the right to modify every file you upload, under the licence you obtained with it. The tool reads what the foundry put inside the file and acts on it: if the Restricted License Embedding bit is set in OS/2.fsType the journey stops, and if the licence is the SIL Open Font License renaming is enforced. These are automated signals and do not replace your own responsibility: the absence of a signal is not permission.

2 — Local processing

All processing happens inside your browser. The tool does not receive, store, or transmit your files to any server, and there is no server to receive them. The technical constraints that make this true are described in How it works.

3 — The currency artwork

The Saudi Riyal, UAE Dirham and Omani Rial symbols come from the issuing authorities (the Saudi Central Bank, the Central Bank of the UAE, the Central Bank of Oman) and are added unchanged rather than redrawn. Your use of them is governed by those authorities, not by this tool.

4 — No warranty

The tool is provided as is, with no warranty of any kind. The resulting file is your responsibility: yours to test before relying on it, and yours to confirm as fit for any commercial use you intend. The in-page verification report is an aid, not a certificate of fitness.

5 — The stamp inside the file

A note is added to the version record inside the file (nameID 5) saying that it was modified with this tool. The purpose is transparency for anyone inspecting it later: whoever opens the file can see it is not as the foundry shipped it.

6 — No tracking

No data is collected about the contents of your files: no font names, no sizes, nothing read from the file.
